# Ключевые топики turtlesim

## 1. Топик `/turtle1/cmd_vel`
- **Тип сообщения:** `geometry_msgs/msg/Twist`
- **Функциональное назначение:** Приём команд управления кинематикой черепахи (задание векторов скорости).

### Структура сообщения Twist:
- **`linear`** (вектор линейной скорости, м/с):
  - `x`: поступательное движение вдоль продольной оси (вперёд / назад).
  - `y`: боковое смещение (стрейф влево / вправо).
  - `z`: вертикальное перемещение (вверх / вниз).
- **`angular`** (вектор угловой скорости, рад/с):
  - `x`: вращение вокруг продольной оси (крен, roll).
  - `y`: вращение вокруг поперечной оси (тангаж, pitch).
  - `z`: вращение вокруг вертикальной оси (рыскание, yaw) — поворот корпуса влево / вправо.

## 2. Топик `/turtle1/pose`
- **Тип сообщения:** `turtlesim/msg/Pose`
- **Функциональное назначение:** Периодическая публикация актуального состояния черепахи (координаты, ориентация, скорости) в реальном времени.

### Структура сообщения Pose:
- `x`: текущая координата по оси абсцисс (диапазон значений от 0 до 11).
- `y`: текущая координата по оси ординат (диапазон значений от 0 до 11).
- `theta`: текущий угол ориентации корпуса в радианах.
- `linear_velocity`: модуль текущей линейной скорости.
- `angular_velocity`: модуль текущей угловой скорости.
