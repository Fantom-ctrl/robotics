# Различия между операторами > и |

### Оператор >:
```
Перенаправляет стандартный вывод команды в файл, заменяя его содержимое.
```
#### Пример:

`ls > list.txt` 
```
Содержимое каталога записывается в файл list.txt, вывод в терминал отсутствует.
```
### Оператор |:
```
Организует конвейер: стандартный вывод первой команды передаётся на стандартный ввод второй команды. Данные не сохраняются в файловой системе.
```
#### Пример:

`ls | grep "txt"` 

```
Осуществляется фильтрация списка файлов по наличию подстроки "txt".
```

# Различия между source и прямым запуском скрипта

### Прямой запуск (./script.sh): 
```
Команды выполняются в дочернем процессе. Изменения окружения, произведённые в скрипте, изолированы от родительского терминала и утрачиваются по завершении процесса.
```

### Команда source (source script.sh): 
```
Команды интерпретируются в контексте текущего процесса оболочки. Все модификации окружения (переменные, алиасы, функции) сохраняются в текущей сессии.
```

# Применяемые команды

### Неверная команда (сбой):

```
ros2 topic pub /cmd_vel geometry_msgs/msg/Twist \
  "{linear: {x: 1.0}, angular: {z: 0.5}}"
```

### Корректная команда (исправление):
```
ros2 topic pub /turtle1/cmd_vel geometry_msgs/msg/Twist \
  "{linear: {x: 1.0}, angular: {z: 0.5}}"
```

## Сравнение конечных точек

| Топик | Publisher | Subscriber |
|----|----|----|
| `/cmd_vel` | `_ros2cli` | `0` |
|`/turtle1/cmd_vel` | `0 → _ros2cli`  | `turtlesim` |

## Анализ причин

```
До: Несмотря на совпадение типа сообщения geometry_msgs/msg/Twist, publisher и subscriber используют разные имена топиков. Соединение не устанавливается, команды не поступают в ноду turtlesim.

После: Publisher и subscriber используют идентичное имя топика /turtle1/cmd_vel и совпадающий тип сообщения. Соединение устанавливается, команды успешно обрабатываются нодой turtlesim.
```

## Условия установления соединения в ROS 2

```
Для формирования связи между publisher и subscriber необходимо одновременное совпадение трёх параметров:

1. Имя топика (например, /turtle1/cmd_vel)
2. Тип сообщения (например, geometry_msgs/msg/Twist)
3. QoS-профиль (параметры надёжности, глубины истории и т.д.)

Несовпадение хотя бы одного из параметров препятствует установке соединения. В рассмотренном случае расхождение наблюдалось по имени топика.
```
