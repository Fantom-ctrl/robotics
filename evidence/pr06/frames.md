# Дерево tf2 модели course_ackermann

Публикации в дерево преобразований осуществляет нода `/robot_state_publisher`. Согласно архитектуре `tf2`, для топика `/tf_static` должен существовать ровно один издатель, и в данной модели это требование строго соблюдено.

Модель описывает три сенсорных звена, жёстко закреплённых на корпусе (`base_link`):

- **`lidar_link`** — лидар, присоединён через `lidar_joint` со смещением вперёд по оси X (приблизительно на половину колёсной базы минус 5 см);
- **`camera_link`** — камера, установлена в передней части корпуса (смещение `base_length/2` по оси X);
- **`imu_link`** — инерциальный модуль, расположен в центре корпуса по горизонтали и приподнят над основанием на сумму половины высоты корпуса и половины высоты самого IMU.

Поскольку все три соединения имеют тип `fixed`, их пространственные преобразования неизменны во времени и публикуются однократно через `/tf_static`. Каждый сенсор позиционируется относительно `base_link` независимо, без промежуточной иерархии между самими сенсорами.

Подвижные элементы шасси (колёса и рулевые механизмы) в URDF-описании отсутствуют, поэтому динамический топик `/tf` не содержит данных и остаётся пустым. Весь граф преобразований модели исчерпывается статическими связями, передаваемыми через `TRANSIENT_LOCAL`-издателя.
